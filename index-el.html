Το πλαίσιό σου, σε όλες τις συσκευές σου.

Το PUKNO Sync προορίζεται να διατηρεί τη μνήμη και το προσωπικό σου πλαίσιο διαθέσιμα στις εξουσιοδοτημένες συσκευές σου με κρυπτογράφηση από άκρο σε άκρο, ενώ το επίπεδο συγχρονισμού μεταφέρει κρυπτογραφημένα δεδομένα χωρίς να χρειάζεται να κατανοεί το περιεχόμενό τους.

PUKNO Private Compute - ΜΕΛΛΟΝΤΙΚΑ

Περισσότερη νοημοσύνη όταν τη χρειάζεσαι.

Στο μέλλον, πιο απαιτητικές εργασίες μπορεί να χρησιμοποιούν μεγαλύτερα μοντέλα σε προστατευμένα περιβάλλοντα εμπιστευτικής υπολογιστικής — αλλά μόνο με τη ρητή συγκατάθεσή σου και σύμφωνα με ρυθμίσεις που ελέγχεις εσύ. Το προσωπικό σου πλαίσιο παραμένει ιδιωτικό, ακόμη κι όταν το μοντέλο είναι απομακρυσμένο.

PUKNO Agents - ΜΕΛΛΟΝΤΙΚΑ

Μετέτρεψε τη μνήμη και το πλαίσιο σε δράση.

Τα PUKNO Agents προορίζονται να ανακτούν το πλαίσιο που σχετίζεται με τον στόχο σου, να επιλέγουν τα απαραίτητα εργαλεία και να εκτελούν πολλαπλά βήματα στον υπολογιστή, στις εφαρμογές και στις συνδεδεμένες υπηρεσίες σου — πάντα για λογαριασμό σου.

Τι θυμάται το PUKNO;

Το PUKNO ξεκινά θυμούμενο τη δραστηριότητα στο Mac σου — ποιες εφαρμογές χρησιμοποίησες, με τι ασχολήθηκες και πότε συνέβη. Μετατρέπει αυτή τη δραστηριότητα σε ένα χρονολόγιο με δυνατότητα αναζήτησης, που σε βοηθά να επιστρέφεις σε πράγματα που ίσως δεν θυμάσαι πια με ακρίβεια.

Λειτουργεί το PUKNO χωρίς σύνδεση στο διαδίκτυο;

Ναι. Σήμερα, το PUKNO εκτελείται και επεξεργάζεται τη δραστηριότητά σου τοπικά στο Mac σου. Η βασική καταγραφή δραστηριότητας, το ιστορικό και η τοπική ανάκληση μπορούν να λειτουργούν χωρίς να στέλνουν το προσωπικό σου πλαίσιο σε απομακρυσμένη υπηρεσία τεχνητής νοημοσύνης.

Σε μελλοντικές εκδόσεις, θα μπορείς προαιρετικά να συνδέσεις το PUKNO με τον δικό σου σταθμό εργασίας AI ή να χρησιμοποιήσεις το PUKNO Private Compute για εργασίες που ωφελούνται από ισχυρότερα μοντέλα.

Φεύγουν τα δεδομένα μου από τη συσκευή μου;

Από προεπιλογή, το PUKNO δίνει προτεραιότητα στην τοπική λειτουργία. Το ιστορικό δραστηριότητας, η μνήμη και το προσωπικό σου πλαίσιο έχουν σχεδιαστεί ώστε να παραμένουν στις συσκευές σου.

Μελλοντικές δυνατότητες, όπως το PUKNO Sync και το PUKNO Private Compute, σχεδιάζονται για να επεκτείνουν όσα μπορεί να κάνει το PUKNO χωρίς να του δίνουν απεριόριστη πρόσβαση στα προσωπικά σου δεδομένα. Η απομακρυσμένη επεξεργασία θα γίνεται μόνο όταν απαιτείται για μια λειτουργία που επιλέγεις να χρησιμοποιήσεις και σύμφωνα με τους ελέγχους ιδιωτικότητας της υπηρεσίας.

Μπορεί το PUKNO να ενεργεί για λογαριασμό μου;

Όχι ακόμη. Το PUKNO ξεκινά με τη μνήμη, το πλαίσιο και τον συλλογισμό. Τα μελλοντικά PUKNO Agents προορίζονται να προχωρήσουν πέρα από τις απαντήσεις: να κατανοούν τι θέλεις να πετύχεις, να επιλέγουν τα εργαλεία που χρειάζονται και να εκτελούν τα βήματα για εσένα.

Αυτό θα μπορούσε να σημαίνει εύρεση πληροφοριών που είδες παλιότερα, εργασία με αρχεία, πλοήγηση σε εφαρμογές, δημιουργία συμβάντων ημερολογίου, αποστολή μηνυμάτων ή ολοκλήρωση εργασιών πολλών βημάτων στο Mac και στις συνδεδεμένες υπηρεσίες σου.

Η διαφορά είναι το πλαίσιο: τα PUKNO Agents προορίζονται να ενεργούν αξιοποιώντας την προσωπική μνήμη που έχει ήδη δημιουργήσει το PUKNO, ώστε να μπορείς να ζητάς «Κλείσε το ξενοδοχείο που κοιτούσα την περασμένη εβδομάδα» χωρίς να χρειάζεται να εξηγείς τα πάντα από την αρχή.

Ποιες πλατφόρμες υποστηρίζονται;

macOS
Το PUKNO αναπτύσσεται αυτή τη στιγμή για macOS, με τις πρώτες εκδόσεις να εστιάζουν σε Mac με Apple silicon. Η έκδοση macOS αποτελεί τον κύριο στόχο ανάπτυξης και την πρώτη πλατφόρμα όπου δημιουργούνται οι δυνατότητες καταγραφής δραστηριότητας, τοπικού πλαισίου και μνήμης του PUKNO.

Windows
Η υποστήριξη των Windows είναι προγραμματισμένη. Το PUKNO θα χρησιμοποιεί τα εγγενή API συστήματος και προσβασιμότητας των Windows για να κατανοεί με ποιες εφαρμογές, παράθυρα και ροές εργασίας αλληλεπιδράς, δημιουργώντας το ίδιο ιδιωτικό πλαίσιο δραστηριότητας και την ίδια προσωπική μνήμη που προσφέρει στο macOS.

Linux
Η υποστήριξη του Linux είναι επίσης προγραμματισμένη, με ενσωματώσεις ειδικά για κάθε περιβάλλον επιφάνειας εργασίας αντί για μία ενιαία γενική υλοποίηση. Οι αρχικοί στόχοι περιλαμβάνουν το GNOME και το COSMIC Desktop, με την υποστήριξη να διαμορφώνεται ανάλογα με τα API και το μοντέλο ασφάλειας κάθε περιβάλλοντος και διαχειριστή σύνθεσης παραθύρων.

Σε κάθε πλατφόρμα, ο στόχος παραμένει ο ίδιος: να καταγράφονται μόνο τα στοιχεία δραστηριότητας που χρειάζονται για τη δημιουργία του προσωπικού σου πλαισίου και του PUKNO Memory, με σεβασμό στο μοντέλο ασφάλειας, ιδιωτικότητας και δικαιωμάτων κάθε λειτουργικού συστήματος.

Διαθέσιμα σήμερα

PUKNO Activity Capture
Το PUKNO καταγράφει και οργανώνει τη δραστηριότητα στο Mac σου — τις εφαρμογές που χρησιμοποιείς, το πλαίσιο εφαρμογών και παραθύρων, τις περιόδους χρήσης, τις χρονικές σημάνσεις και την υποστηριζόμενη δραστηριότητα στον ιστό. Έτσι δημιουργείται ένα ιδιωτικό ιστορικό του τι έκανες και πότε, το οποίο χρησιμοποιεί το PUKNO Memory για αναζήτηση και συνομιλία.

PUKNO Memory
Η μνήμη είναι ενσωματωμένη στην αναζήτηση και τη συνομιλία. Αναζήτησε καταγεγραμμένα στιγμιότυπα ανά θέμα, ρώτησε για δραστηριότητα που θυμάσαι και ανάκτησε σχετικές στιγμές με το πλαίσιό τους και κάρτες πηγών — ακόμη και βίντεο που παρακολούθησες.

Τι ετοιμάζουμε

PUKNO Sync
Το PUKNO Sync προορίζεται να κάνει τη μνήμη, το πλαίσιο και την προσωπική σου νοημοσύνη διαθέσιμα σε όλες τις συσκευές σου, διατηρώντας τα ιδιωτικά. Η δραστηριότητα, οι αναμνήσεις και το προσωπικό σου πλαίσιο θα προστατεύονται με κρυπτογράφηση από άκρο σε άκρο, ώστε να έχουν πρόσβαση μόνο οι εξουσιοδοτημένες συσκευές σου.

Το επίπεδο συγχρονισμού προορίζεται να μεταφέρει κρυπτογραφημένα δεδομένα, όχι να κατανοεί το περιεχόμενό τους. Ο μελλοντικός συγχρονισμός του PUKNO δεν θα πρέπει να χρειάζεται πρόσβαση στο αναγνώσιμο περιεχόμενο της μνήμης σου, ώστε οι συσκευές σου να παραμένουν συγχρονισμένες και να συνεχίζουν να χτίζουν το ίδιο προσωπικό πλαίσιο.

PUKNO Private Compute
Το PUKNO έχει σχεδιαστεί για να διατηρεί το προσωπικό πλαίσιο και την επεξεργασία AI τοπικά, όπου είναι δυνατό. Ορισμένα αιτήματα, ωστόσο, μπορεί να ωφελούνται από μοντέλα που είναι πολύ μεγάλα ή υπολογιστικά απαιτητικά για να εκτελούνται αποδοτικά στη συσκευή σου.

Το PUKNO Private Compute προορίζεται να προσφέρει έναν τρόπο πρόσβασης σε αυτή την πρόσθετη υπολογιστική ισχύ που προστατεύει την ιδιωτικότητα. Όταν εγκρίνεις ρητά ένα αίτημα, το PUKNO θα μπορεί να προετοιμάζει μόνο το πλαίσιο που απαιτείται για την εργασία και να το στέλνει σε ένα απομονωμένο περιβάλλον εμπιστευτικής υπολογιστικής με ένα ισχυρότερο μοντέλο.

Στόχος είναι να δώσει στο PUKNO πρόσβαση σε ισχυρή απομακρυσμένη εκτέλεση μοντέλων όταν χρειάζεται, χωρίς να εκθέτει την ευρύτερη προσωπική σου μνήμη στην υποδομή που παρέχει την υπολογιστική ισχύ.

Αυτό θα μπορούσε στο μέλλον να προσφέρεται μέσω υποδομών του PUKNO ή συμβατών υπηρεσιών εμπιστευτικής υπολογιστικής. Θα ενεργοποιείται μόνο όταν χρειάζεται, μόνο με τη ρητή συγκατάθεσή σου και πάντα υπό τον έλεγχό σου. Θα αποστέλλεται μόνο το πλαίσιο που απαιτείται για την εργασία που εγκρίνεις. Τα δεδομένα θα κρυπτογραφούνται κατά τη μεταφορά και την αποθήκευση και θα υποβάλλονται σε επεξεργασία μόνο μέσα στο προστατευμένο υπολογιστικό περιβάλλον.

PUKNO Agents
Τα PUKNO Agents προορίζονται να μετατρέπουν τη μνήμη, το πλαίσιο και τον συλλογισμό σε δράση. Ένας πράκτορας θα μπορεί να κατανοεί τι θέλεις να πετύχεις, να ανακτά το σχετικό προσωπικό πλαίσιο, να αποφασίζει ποια εργαλεία χρειάζονται και να εκτελεί πολλαπλά βήματα στον υπολογιστή, στις εφαρμογές και στις συνδεδεμένες υπηρεσίες σου.

Αντί να απαντά μόνο «Ποιο ξενοδοχείο κοιτούσα;», ένας PUKNO Agent θα μπορούσε στο μέλλον να κατανοεί το «Κλείσε το ξενοδοχείο που κοιτούσα την περασμένη εβδομάδα», να ανακτά τη σχετική μνήμη, να εντοπίζει το ξενοδοχείο που εννοείς, να επιλέγει τα κατάλληλα εργαλεία και να ολοκληρώνει την εργασία για λογαριασμό σου.
